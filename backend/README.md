# Backend — Focinho Amigo

API em Node.js, Express e TypeScript.

## Configuração

Copie `.env.example` para `.env` e informe banco MySQL Aiven, Supabase e JWT.

## Executar

```bash
npm install
npm run dev
```

## Build e produção

```bash
npm run build
npm start
```

A API fica disponível em `http://localhost:3000` por padrão.
